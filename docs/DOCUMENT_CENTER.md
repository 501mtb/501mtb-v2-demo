# 501MTB V2 document centre

This branch adds a static `documents.html` page and a Documents link in the V2 navigation. The catalog is maintained in HTML.

## Sections
- Public: Policies & Regulations (no file linked yet)
- Team only: Internal Code of Conduct
- Team only: Sponsorship Contracts
- Restricted: Contact Directory

No actual document files or personal contact data are included.

## Confidentiality
GitHub Pages is a public static website. Any file committed to this public repository is public even if no page links to it. Hidden links and folders named private do not provide access control. Do not upload signed sponsorship contracts, internal documents, private contact lists, or personal data. Keep these in a private storage service with access permissions.

This static page is a catalog/guide only; it does not authenticate users or secure private files. A real team-only portal will require authenticated storage or a backend.

Scope: repository `501mtb/501mtb-v2-demo`, branch `feature/document-center`. V1 is not changed.
